## 2026-07-25 - Explicit Form Label Associations and Floating Icon Accessibility

**Learning:** Unassociated `<label>` elements and icon-only/emoji floating links are common accessibility gaps in single-file landing pages.
**Action:** Always link form labels using explicit `for` attributes matching control `id`s, provide descriptive `aria-label`s on icon-only links, and apply `focus-visible` ring utilities to ensure clear keyboard focus indication.
